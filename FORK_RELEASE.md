# DrNetwork release model

This is an independent, full-source repository—not a GitHub fork. Backend and frontend live together on `main` and are maintained here; nothing is synchronized from the official S-UI repositories, and the whole product -- DrNetwork branding, multi-node management, live traffic and the rest -- is developed in this repository.

Tags build Linux and Windows archives plus the multi-architecture container image. The installer, management script and checksum verification all resolve releases from `Danialrostamani/drnetwork-panel`.
